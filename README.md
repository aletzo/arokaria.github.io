# Mezonette Arokaria

The public homepage uses The Kyparissi House (design 4), with English as the default language and a Greek language switch. Earlier design alternatives remain available at their individual URLs.

- `mediterranean-calm.html`
- `summer-journal.html`
- `sea-and-mountain.html`
- `kyparissi-house.html`

## Preview

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173.

No installation or build is required. GitHub Pages serves these static files directly from the repository root on `master`. Booking links point to the Airbnb listing.
